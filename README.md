
# CardGen — быстрый генератор учебных карточек

Учебный проект по курсу управления проектами (Лабораторная 1: Инициация проекта).

Wiki проекта: https://github.com/ekaterinashavel2005-web/project/wiki
Эксперты: Иван, Мария
## Цель
Помочь студентам быстро превращать Markdown-конспекты в карточки для повторения перед экзаменом, экономя время на ручной подготовке.

## Ключевые функции
- Парсинг Markdown-файла с вопросами и ответами
- Генерация набора карточек для повторения
- Случайный порядок карточек и отметка «знаю / не знаю»

## Формат Markdown-конспекта

Конспект — обычный файл `.md`. Каждая пара «вопрос / ответ» состоит из:
- **вопроса** — строка заголовка второго уровня: `## Вопрос`;
- **ответа** — весь текст до следующего `##` или конца файла (абзацы, списки, код).

Правила:
- Текст до первого `##` (вступление, заголовок файла `#`) в карточки не попадает.
- Пустой вопрос (`##` без текста) или пустой ответ — ошибка формата; такая пара пропускается с предупреждением.
- Вопрос заканчивать знаком `?` не обязательно.

Пример — `content/example.md`:

```markdown
# Конспект: основы сетей

## Что такое IP-адрес?
Числовой идентификатор узла в сети. В IPv4 — четыре октета, например `192.168.0.1`.

## Что делает протокол TCP?
Гарантирует доставку данных по порядку и без потерь, устанавливая соединение.
```

Из этого файла получаются две карточки: «Что такое IP-адрес?» и «Что делает протокол TCP?».

## Структура репозитория

- `data/` — вспомогательные данные
