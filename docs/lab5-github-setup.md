## 3. Поля проекта (Projects → New field)
- Estimate — тип Number.
- Priority — тип Single select (значения из лабораторной 4).
- Start date, Target date — тип Date.
- Iteration — тип Iteration, длительность 1 неделя, 3 итерации: до 2026-11-22, 2026-12-06, 2026-12-20.

## 4. Зависимости
Связи blocked by / blocking между issues по цепочке критического пути:
Загрузчик → Парсер → Генератор → Сессия → Знаю/не знаю → Экспорт JSON → Финальная проверка.
Параллельно: юнит-тесты (после парсера), граничные случаи (после парсера), CLI (после загрузчика), документация (после парсера).

## 5. Views
- «Blocked Tasks» — фильтр `is:blocked`. Если связи недоступны, используй метку `blocked`.
- «Текущий спринт» — тип Board, фильтр по Iteration = текущая.
- Сортировка/фильтр по Estimate — обычный Table view, сортировка по Estimate по убыванию.

## 6. Start и Target date и Road Map
Даты выводятся из критического пути (11 дней, все задачи цепочки идут подряд, без зазоров). Заполни Start date и Target date у каждой задачи, затем создай view Roadmap (тип Roadmap / timeline) и проверь, что даты майлстоунов не раньше последней задачи майлстоуна.

## 7. Wiki
1. Перенеси содержимое `docs/Estimation-draft.md` в страницу Wiki «Estimation».
2. Добавь ссылку на страницу из главной страницы Wiki.
3. Вставь ссылки на GitHub Project и Road Map.
