# Тестовые сценарии CardGen

Сценарии проверяют каждый инкремент. Файлы лежат в `content/`.

| № | Что запускаем | Файл | Ожидаемый результат |
|---|---|---|---|
| 1 | Парсинг нормального конспекта | `content/normal.md` | 5 карточек, вопросы и ответы совпадают с файлом |
| 2 | Парсинг пустого конспекта | `content/empty.md` | 0 карточек, без ошибки; сообщение «в файле нет пар вопрос/ответ» |
| 3 | Парсинг конспекта с ошибками формата | `content/broken.md` | 1 карточка («Нормальный вопрос?»); пустые вопросы пропущены с предупреждением; `###` не считается вопросом |
| 4 | Запуск с несуществующим файлом | `content/missing.md` | Понятная ошибка «файл не найден», код выхода ≠ 0 |
| 5 | Запуск без аргументов | — | Подсказка по использованию (usage), код выхода ≠ 0 |
| 6 | Повторный запуск на `normal.md` | `content/normal.md` | Тот же набор карточек, что в сценарии 1 (детерминированный парсинг) |

Сценарии 4–5 относятся к CLI (#10) и проверяются, когда она появится.
